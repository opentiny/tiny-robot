# 模板块删除逻辑完整说明

## 📋 总览

本文档详细说明模板块（template）的 **Backspace** 和 **Delete** 删除逻辑，包括所有场景、边界情况处理和可能存在的问题。

## 🎯 核心设计原则

1. **保护性删除**：模板块内删除到最后一个字符时，不删除模板块，而是保留零宽字符占位
2. **渐进式退出**：空模板块内按删除键先跳出，再次按才删除整个块
3. **智能进入**：有内容的模板块，删除键会进入而非删除
4. **零宽字符清理**：删除模板块时连带清理前后的零宽字符，保持文档整洁
5. **边界保护**：防止 ProseMirror 默认行为导致模板块边界被破坏

## 🔍 关键场景详解

### 1. 保护性删除（防止模板块消失）

```typescript
// Backspace：光标在模板块末尾，内容只有1个字符
if ($from.pos === $from.end() && content.length === 1 && content !== ZERO_WIDTH_CHAR) {
  const pos = $from.pos - 1
  dispatch(state.tr.insertText(ZERO_WIDTH_CHAR, pos, pos + 1))
  event.preventDefault()
  return true
}
```

**交互示例**：

```
初始：【三】（光标在 "三" 后）
↓ Backspace
结果：【​】（变成空模板块，保留结构）
```

### 2. 渐进式退出（两次操作删除空模板块）

```typescript
// Backspace：跳出到模板块前
if (content === ZERO_WIDTH_CHAR && event.key === 'Backspace') {
  const nodePos = $from.before()
  dispatch(state.tr.setSelection(TextSelection.create(state.doc, nodePos)))
  event.preventDefault()
  return true
}
```

**交互示例**：

```
初始：【​】（光标在内部）
↓ Backspace（第一次）
结果：|【​】（光标跳到前面，模板块保留）
↓ Backspace（第二次）
结果：（整个模板块被删除）
```

### 3. 边界保护（防止文本被吸入模板块）⚠️ 重要

**问题场景**（修复前）：

```
初始：我是【张三】，来自（光标在 "三" 后）
↓ Delete
问题：我是【张三，】来自 ❌（逗号被吸入模板块！）
```

**修复后**：

```typescript
// Delete：光标在模板块末尾时，跳出而不是默认处理
if ($from.pos === $from.end() && content.length > 0 && content !== ZERO_WIDTH_CHAR) {
  const nodePos = $from.after()
  dispatch(state.tr.setSelection(TextSelection.create(state.doc, nodePos)))
  event.preventDefault()
  return true
}
```

**交互示例**：

```
初始：我是【张三】，来自（光标在 "三" 后）
↓ Delete
结果：我是【张三】|，来自 ✅（光标跳出，不破坏边界）
```

### 4. 从外部删除模板块

```typescript
// Backspace：从右侧删除空模板块
if (beforeNode.type.name === 'template' && isEmpty) {
  // 计算删除范围，包括前后零宽字符
  let deleteStart = $from.pos - beforeNode.nodeSize
  let deleteEnd = $from.pos

  if (prevPrevNode?.text?.endsWith(ZERO_WIDTH_CHAR)) deleteStart -= 1
  if (afterNode?.text?.startsWith(ZERO_WIDTH_CHAR)) deleteEnd += 1

  dispatch(state.tr.delete(deleteStart, deleteEnd))
}
```

**交互示例**：

```
空模板块：我是【​】|，来自
↓ Backspace
结果：我是|，来自（模板块和零宽字符一起被清理）

有内容模板块：我是【张三】|，来自
↓ Backspace
结果：我是【张三|】，来自（进入模板块末尾）
```

## ⚠️ 可能存在的问题及处理

| 问题                 | 场景                  | 原因                               | 解决方案                                                                                        | 状态     |
| -------------------- | --------------------- | ---------------------------------- | ----------------------------------------------------------------------------------------------- | -------- |
| **模板块与文本粘连** | 删除模板块内字符后    | 零宽字符被清理，模板块直接贴着文本 | 修改 `handleZeroWidthCharLogic`，在模板块后任何节点前都插入零宽字符（目前仅在两个模板块间插入） | ⚠️未解决 |
| **文本被吸入模板块** | 在模板块边界按删除键  | ProseMirror 默认行为破坏边界       | 添加边界保护逻辑，光标到达边界时直接跳出                                                        | ✅已解决 |
| **零宽字符残留**     | 删除模板块后          | 只删除模板块，未清理周围零宽字符   | 扩展删除范围，检查前后零宽字符并一并删除                                                        | ✅已解决 |
| **光标无法定位**     | 连续模板块之间        | 缺少零宽字符分隔                   | 在连续模板块之间自动插入零宽字符                                                                | ✅已解决 |
| **误删整个模板块**   | 模板块内只有1个字符时 | 直接删除导致模板块消失             | 替换为零宽字符而非删除                                                                          | ✅已解决 |
| **选区删除不完整**   | 选中内容包含零宽字符  | 零宽字符未被选中                   | 扩展选区范围包含前后零宽字符                                                                    | ✅已解决 |

**⚠️ 模板块与文本粘连问题说明**：

当前实现中（`plugins.ts` 第 62-71 行），零宽字符只在连续两个模板块之间插入，**不在模板块和文本之间插入**。代码注释说明这是为了"避免零宽字符被合并到文本节点"。但这会导致删除模板块内容后，模板块和后面的文本粘在一起。

## 📝 总结

### ✅ 已实现的功能

1. **保护性删除** - 删除到最后一个字符时保留模板块
2. **渐进式退出** - 空模板块需要两次操作才能删除
3. **智能进入** - 有内容的模板块会进入而非删除
4. **边界保护** - 防止 ProseMirror 破坏模板块边界
5. **零宽字符清理** - 删除模板块时清理前后零宽字符
6. **选区删除优化** - 扩展选区包含零宽字符

### ⚠️ 待优化的问题

1. **模板块与文本粘连** - 需要在模板块和文本之间也插入零宽字符
2. **性能优化** - 批量操作时的零宽字符处理
3. **输入法支持** - 中文输入法时的零宽字符处理

### 🎯 Backspace vs Delete 对比

| 维度               | Backspace                          | Delete                               |
| ------------------ | ---------------------------------- | ------------------------------------ |
| **方向**           | ← 向左删除                         | → 向右删除                           |
| **检查节点**       | `$from.nodeBefore`                 | `$from.nodeAfter`                    |
| **模板块位置判断** | `$from.pos === $from.end()` (末尾) | `$from.pos === $from.start()` (开头) |
| **跳出位置**       | `$from.before()` (前面)            | `$from.after()` (后面)               |
| **进入位置**       | `$from.pos - 1` (末尾)             | `$from.pos + 1` (开头)               |
| **跳过零宽字符**   | `$from.pos - 2`                    | `$from.pos + 2`                      |
| **删除范围扩展**   | 检查前面和后面的零宽字符           | 检查前面和后面的零宽字符             |
