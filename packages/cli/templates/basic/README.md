# __PROJECT_NAME__

TinyRobot AI chat starter built with Vue 3 + Vite.

## Setup

1. Copy environment variables:

```bash
cp .env.example .env
```

2. Fill your provider keys in `.env`:

```env
VITE_ALIYUN_DASHSCOPE_KEY=your_dashscope_key
VITE_DEEPSEEK_API_KEY=your_deepseek_key
```

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm preview
```
