# TinyRobot Chat Cases

Product validation cases for `@opentiny/tiny-robot-chat`.

The default entry renders the TinyRobot full-screen case. The right-panel and floating cases are available under `src/cases/tiny-robot` for route integration.

## Development

```bash
pnpm -F chat-cases dev
```

## Build

```bash
pnpm -F chat-cases build
```
