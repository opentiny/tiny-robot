01 / Reuse

复用核心

TinyRobotAssistant 接收 Runtime，直接渲染 TrChat，不重新实现会话逻辑。

02 / Extend

扩展 UI

createTinyRobotChatUi 和 composer-before Slot 负责品牌、Prompt、Header 和输入区定制。

03 / Shape

变化形态

useTinyRobotWindow 管理悬浮、侧边、全屏和拖拽，窗口变化不影响 ChatRuntime。

07

CLI：把 Chat 标准交付给项目

CLI 不重新实现 Chat；它把已经验证的两种接入形态，分别交付给新项目和存量项目。

create

create → chat-basic

生成一个完整的新项目，默认使用最小标准 Chat 作为起点。

add chat

add chat → chat-add

向已有 Vue 项目注入独立 Chat 特性，保留宿主项目并降低接入冲突。

新项目：从标准实现开始

create 对应 packages/cli/templates/basic，产物与 chat-basic 保持一致，适合作为产品研发的基线。

createpackages/cli/README.md
npx @opentiny/tiny-robot-cli create my-app
npx @opentiny/tiny-robot-cli create my-app --template basic

存量项目：注入 Chat 能力

add chat 对应 packages/cli/templates/chat，生成 src/tiny-robot-chat/，并处理依赖、样式和 MCP 代理。

add chatpackages/cli/README.md
npx @opentiny/tiny-robot-cli add chat --yes
npx @opentiny/tiny-robot-cli add chat --dry-run
关键关系：Chat 是能力和协议的来源；chat-basic、chat-add 是标准落地形态；CLI 只是把它们分发到不同项目生命周期。
