## Logo

`logo.svg` 的图形部分使用 `#1476FF`，字标在浅色模式下为黑色，在深色模式下为白色。文章头图、封面和文档页中可以优先使用蓝色图形标识，不建议重新绘制或改造字形。

## 色彩

可复用主色：

- `#1476FF`：本地 Logo 主色，也是官网导航图标和按钮高亮的核心蓝。
- `#5E7CE0`：官网 SVG 图标与 TinyEngine 页面中常见的蓝紫色。
- `#7693F5` / `#96ADFA`：官网插画、渐变和科技感辅助色。
- `#191919`：官网和文档中常见正文深色。
- 白色、极浅蓝、浅灰作为大面积背景。

视觉整体是蓝白科技风，不是重紫、深色赛博或强营销渐变。适合使用高亮蓝、柔和阴影、浅色卡片和轻量 3D 插画。

## 官网首页观察

官网首屏呈现：

- 顶部产品导航包含 TinyVue、TinyEngine、TinyRobot、NEXT-SDKs、GenUI-SDK、AI-Extension。
- 主视觉围绕 OpenTiny NEXT 和 MCP 生态，使用蓝白 3D 模块、中心节点和箭头连接。
- 首屏大标题强势，副标题解释技术创新，按钮保持描边圆角。
- 下方内容用“改造前/改造后”对比卡片承接业务场景，强调应用智能化前后的效率差异。

用于文章封面时，可以借鉴“产品名 + 核心主题 + 蓝白 3D/流程节点”的组合，不必堆叠太多代码截图。

## GitHub 组织页观察

GitHub 组织页视觉更偏工程可信度：

- 组织头像为蓝黄立方体图形。
- 页面重点展示组织描述、followers、置顶仓库和 topics。
- 仓库卡片突出产品生态：`tiny-engine`、`tiny-vue`、`tiny-editor`、`tiny-robot`、`webmcp-sdk`、`genui-sdk`。
- 技术标签集中在 TypeScript、JavaScript、Vue、Less、HTML，以及 `ai`、`frontend`、`tiny-vue`、`opentiny`。

文章引用 GitHub 证据时，适合用仓库截图或产品矩阵图，突出“生态完整”和“开源可信”。

## 掘金文章页观察

掘金页采用平台默认文章样式，OpenTiny 的识别度主要来自：

- 标题中的产品名和版本号。
- 正文中的 emoji 小节标记。
- 右侧作者卡片显示 OpenTiny 社区、文章数、阅读量。
- 目录结构清晰，标题层级从“特性总览”到“核心亮点解析”“升级指南”“关于 OpenTiny NEXT”。

面向掘金的文章视觉可以保留平台友好的轻量风格：明确目录、短段落、粗体关键词、列表化卖点、必要时插入 GIF 或功能截图。

## 文章配图建议

- 发布类：产品名、版本号、3-4 个关键特性、蓝白科技底色。
- 教程类：操作流程图、代码片段截图、前后对比图。
- AI / NEXT 类：Agent、MCP、生成式 UI、浏览器自动化等概念用节点连接、对话气泡、应用界面生成效果表达。
- 生态类：用产品矩阵图展示 TinyVue、TinyEngine、TinyRobot、GenUI SDK、NEXT-SDKs 的关系。

## 视觉禁区

- 不使用与 OpenTiny 无关的重插画、游戏化图标或夸张霓虹风。
- 不把 AI 视觉做成泛化机器人头像；需要落到 UI、Agent、MCP、流程自动化或生成式界面。
- 不在封面堆太多文字，主标题保留一个核心卖点即可。
