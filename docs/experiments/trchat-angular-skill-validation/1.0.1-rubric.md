# Angular 1.0.1-based Web Component validation rubric

## Provenance boundary

The upstream baseline is source tag `v1.0.1`. The registry artifact `@opentiny/tiny-robot-chat@1.0.1` does **not** publish the Web Component entrypoints. Every Angular fixture must therefore install locally packed `1.0.1` candidate tarballs from this branch and prove that the installed Chat manifest exports both `./experimental` and `./experimental/web-component.css`. A result from the registry Chat package does not satisfy this rubric.

## Fixtures

- Angular 20 standalone CSR application.
- Angular 20 NgModule CSR application with `standalone: false` at the declaring boundary.
- Angular 20 SSR/hydration application that registers and creates TrChat only in the browser.

All fixtures must use public package entrypoints and remain isolated from workspace links and private source imports.

## Acceptance criteria

| Area | Required evidence |
| --- | --- |
| Candidate provenance | Exact `1.0.1` manifests, candidate experimental exports, canonical package paths inside each fixture's `node_modules`, and lockfiles resolving the candidate tarballs. |
| Registration and properties | Repeat-safe browser registration and complex JavaScript property assignment in every applicable Angular host mode. |
| Model features | Multiple models, switch/select feature values, `model-feature-value-change`, and runtime state synchronization. |
| History and attachments | Conversation create/switch/rename/delete/search/restore flows and image attachment select/remove/submit/clear flows. |
| MCP and Skills | Deterministic local MCP `tools/call` and application Skill instruction injection through public APIs. |
| Renderers and actions | Built-in/custom renderer precedence, equal-priority match order, Markdown fallback, message actions, DOM methods and DOM event details. |
| Angular state boundaries | Controlled right-aside and floating state update in both directions without serializing objects through attributes. |
| Provider security | Same-origin application proxy and deterministic local provider; no real credential in source, element properties, browser assets, or source maps. |
| Responsive visual result | Browser screenshots and geometry checks at desktop and 390 px; no document-level horizontal overflow or blocking console/page errors. |
| NgModule mode | A real non-standalone declaring component renders TrChat and completes property/event/runtime flow. |
| SSR/hydration | HTTP 200 server HTML contains the loading placeholder and `ngSkipHydration`, contains no server-created `<tr-chat>`, then browser registration, readiness, property, method and real Reasoning-switch event flow complete. |
| Repository regression | Chat unit/type/build, release/Skill checks, candidate installation, full E2E and full component suites pass. |

Screenshots support visual claims but do not replace runtime traces. Real DeepSeek behavior and credentials remain out of scope; deterministic local endpoints keep the suite unattended and reproducible.
